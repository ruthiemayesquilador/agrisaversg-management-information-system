# agrisaversg-management-information-system

The Agri Savers G Management Information System manages products, stock, suppliers, POS transactions, accounting, reporting, and inventory operations.

## Framework

Built with [CodeIgniter 4](https://codeigniter.com). See the [CodeIgniter user guide](https://codeigniter.com/user_guide/) for framework documentation.

## Deployment

Configure the web server document root to point to the `public` directory, not the project root. This keeps application and framework files outside the web-accessible directory.
